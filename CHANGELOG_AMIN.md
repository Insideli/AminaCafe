# Что изменено в версии AminaCafe-improved

## Paloma365

- Удалён опубликованный API AUTHKEY из исходного кода.
- Добавлен безопасный Vercel-прокси `api/paloma.js` с белым списком операций, таймаутом и проверкой входных данных.
- Добавлены операции: проверка связи, точки, меню, стоп-лист, отправка заказа и статус заказа.
- Меню и стоп-лист теперь синхронизируются вместе.
- У заказа проверяются Paloma ID блюд; заказ без синхронизированного меню не отправляется молча.
- Исправлен `delivery_type` по публичному примеру Tester API: доставка — `1`, остальные заказы — `0` с номером стола в комментарии.
- Добавлены телефон, email, адрес, количество гостей, скидка и информативный комментарий.
- Ошибка Paloma не удаляет локальный заказ: сотрудник получает предупреждение, а в заказ записывается `palomaSync.status = failed`.
- Успешный ответ сохраняет `paloma_order_id` и `receipt_id`.
- Убраны повторные отправки заказа при закрытии/оплате стола, которые могли создавать дубликаты в Paloma365.

## Надёжность

- Удалён ошибочный автозапуск синхронизации из `App.jsx`, где использовались несуществующие `menu` и `setMenu`.
- Гостевой экран больше не обращается к Paloma при каждом открытии; он использует последнюю сохранённую версию меню из Firestore.
- Случайные четырёхзначные номера заказов заменены на практически уникальные ID на основе времени и криптографического случайного числа.
- Исправлен `vercel.json`: SMS и другие serverless-функции больше не перенаправляются в Paloma-прокси.

## UI администратора

- Добавлена кнопка проверки соединения с Paloma365.
- Добавлен понятный статус: ожидание, успешно, ошибка.
- Кнопка синхронизации блокируется во время запроса.
- После синхронизации показывается количество блюд и позиций стоп-листа.

## Новая структура

- `src/api/palomaClient.js` — HTTP-клиент фронтенда.
- `src/services/palomaService.js` — преобразование меню и заказов.
- `src/utils/orderId.js` — генерация ID заказов.
- `PALOMA_SETUP.md` — пошаговая настройка Paloma365 и Vercel.
- `.env.example` — список необходимых серверных переменных.

## Выполненные проверки

- Все JS/JSX-файлы успешно разобраны парсером TypeScript без синтаксических ошибок.
- Серверный Paloma-прокси проверен мок-тестом: метод, point_id, тело заказа и отсутствие утечки ключа в ответ.
- `buildPalomaOrder` проверен тестовым заказом.
- `vercel.json` проверен как корректный JSON.

Полную Vite-сборку в среде проверки выполнить не удалось: внутренний npm-реестр не отдал один из пакетов. Это ограничение среды проверки, а не найденная ошибка проекта.
