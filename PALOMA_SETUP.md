# Подключение AminaCafe к Paloma365

## 1. Срочно замените старый ключ

В предыдущей версии проекта API AUTHKEY был записан прямо в `api/paloma.js`. Такой ключ считается скомпрометированным.

1. Откройте Paloma365: **Предприятие → Управление → Настройки аккаунта**.
2. Перевыпустите/сгенерируйте новый **API AUTHKEY**.
3. Старый ключ больше не используйте.
4. Не отправляйте новый ключ в чат и не добавляйте его в GitHub.

## 2. Настройте внешний сервис Tester

В Paloma365 должна быть включена конфигурация внешнего сервиса с ключом/классом `Tester`. В ней выбираются меню и вид безналичной оплаты. Если такой конфигурации нет, обратитесь к поддержке Paloma365 или к специалисту, который настраивает кассу.

## 3. Узнайте ID торговой точки

API умеет получать список точек методом `points`. После настройки переменных откройте:

`https://ВАШ-ДОМЕН.vercel.app/api/paloma?action=health`

В ответе будет массив `points`. Скопируйте нужный `point_id`.

## 4. Добавьте переменные в Vercel

Vercel → Project → Settings → Environment Variables:

- `PALOMA_AUTHKEY` — новый ключ;
- `PALOMA_POINT_ID` — ID торговой точки;
- `PALOMA_HOST` — `https://api.paloma365.com` (можно не задавать).

Добавьте значения минимум для Production и Preview, затем выполните новый Deploy.

## 5. Как запускать локально

Обычный `npm run dev` запускает только Vite и не поднимает `/api/paloma`.
Для полной локальной проверки используйте Vercel CLI (`vercel dev`) и локальный `.env.local`, который нельзя коммитить.

## 6. Проверка

1. `/api/paloma?action=health` возвращает `{ "ok": true, ... }`.
2. В админке нажмите **«Синхронизировать с Paloma»**.
3. Проверьте, что загрузились категории, блюда и стоп-лист.
4. Создайте тестовый заказ из одного дешёвого блюда.
5. В Paloma365 проверьте новый онлайн-заказ.

## Важное ограничение Tester API

В опубликованной документации `delivery_type` имеет значения:

- `1` — доставка;
- `0` — самовывоз.

Отдельного типа «заказ в зале» там не описано. Поэтому AminaCafe отправляет заказ в зале как `0`, а номер стола записывает в `comment`. Перед реальным запуском Кирилл/поддержка Paloma365 должны подтвердить, что для вашей конфигурации это правильная схема.
